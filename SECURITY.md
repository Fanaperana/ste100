# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Report a vulnerability

Do **not** open a public issue for a security problem.

Report it privately with GitHub's [private vulnerability reporting](https://github.com/Fanaperana/ste100/security/advisories/new).

Include:

- A description of the problem and its possible effect.
- The steps to reproduce it.
- The plugin version and your Claude Code version.

You get a first reply within 7 days. When the problem is confirmed, a fix is released as quickly as possible. You get credit in the advisory if you want it.

## Scope

This plugin adds text to Claude's system prompt and stores one on/off value. It does not run commands, read files or use the network. Report problems in Claude Code itself to [Anthropic](https://www.anthropic.com/responsible-disclosure-policy).
