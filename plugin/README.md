# ste100

Makes Claude write its answers in ASD-STE100 Simplified Technical English: short sentences, active voice, simple words, the result first, and no filler. Code, commands and paths are not changed.

It is on by default. Use `/ste on`, `/ste off`, or `/ste` to toggle. The choice is kept across sessions.

Full documentation: https://github.com/Fanaperana/ste100

## Install

```text
/plugin install ste100 --marketplace Fanaperana/ste100
```
