# Support

- **Questions and ideas:** [open an issue](https://github.com/Fanaperana/ste100/issues/new/choose).
- **Bugs:** use the [bug report template](https://github.com/Fanaperana/ste100/issues/new?template=bug_report.yml).
- **Security problems:** read [SECURITY.md](SECURITY.md). Do not open a public issue.
- **Claude Code help:** read the [Claude Code documentation](https://docs.claude.com/en/docs/claude-code).
